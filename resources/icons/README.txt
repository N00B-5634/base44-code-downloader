YellowDocs Icons
==================

This directory contains SVG vector icons for YellowDocs Writer.

Application Icons:
- app_icon.svg: Main application icon (64x64)
- document_icon.svg: Document icon (64x64)

Toolbar Icons (24x24):
- new.svg: New document
- open.svg: Open document
- save.svg: Save document
- bold.svg: Bold formatting
- italic.svg: Italic formatting
- underline.svg: Underline formatting
- align_left.svg: Left alignment
- align_center.svg: Center alignment
- align_right.svg: Right alignment
- align_justify.svg: Justify alignment

Icon Design:
- Color Scheme: Warm yellow/amber (#FFBF00 - #FFD700 gradient)
- Style: Flat, clean design matching Haiku system icons
- Background: Transparent
- Format: SVG vector format for scalability

To convert SVG to PNG for Haiku:
1. Use Inkscape or similar vector graphics editor
2. Export at required sizes (16x16, 32x32, 64x64)
3. Save as PNG with transparent background
4. Optimize file size

Icon Naming Convention:
- Use lowercase filenames
- Use underscores for multi-word names
- Include size in filename if multiple sizes exist

All icons are original creations for YellowDocs and do not infringe on any existing copyrights.
