# YellowDocs Icons

This directory contains icons for YellowDocs applications.

## Directory Structure

- `16x16/`: 16x16 pixel icons (mini icons)
- `32x32/`: 32x32 pixel icons (small icons)
- `64x64/`: 64x64 pixel icons (large icons)
- `scalable/`: SVG vector icons (for future use)
- `toolbar_icons/`: Toolbar-specific icons

## Icon Files

### Application Icons

- `app_icon.png`: Main application icon (64x64)
- `app_icon_32.png`: Application icon (32x32)
- `app_icon_16.png`: Application icon (16x16)

### Document Icons

- `document_icon.png`: Document icon (64x64)
- `document_icon_32.png`: Document icon (32x32)
- `document_icon_16.png`: Document icon (16x16)

### Toolbar Icons

Toolbar icons are stored in the `toolbar_icons/` directory:

- `new.png`: New document
- `open.png`: Open document
- `save.png`: Save document
- `bold.png`: Bold formatting
- `italic.png`: Italic formatting
- `underline.png`: Underline formatting
- `align_left.png`: Left alignment
- `align_center.png`: Center alignment
- `align_right.png`: Right alignment
- `align_justify.png`: Justify alignment

## Icon Design Guidelines

- **Color Scheme**: Use warm yellow/amber (#FFBF00) as accent color
- **Style**: Flat, clean design matching Haiku system icons
- **Background**: Transparent background for all icons
- **Format**: PNG format for raster icons
- **Size**: Exact pixel dimensions as directory names suggest

## Creating Icons

Icons can be created using any graphics editor. For best results:

1. Use vector graphics software (Inkscape, Illustrator, etc.)
2. Design at 64x64 pixels for best quality
3. Scale down to 32x32 and 16x16 for smaller sizes
4. Export as PNG with transparent background
5. Optimize file size

## Icon Naming Convention

- Use lowercase filenames with underscores
- Include size in filename for multi-size icons
- Use descriptive names for toolbar icons
